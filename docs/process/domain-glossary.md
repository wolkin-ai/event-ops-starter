# Domain Glossary

| Term                 | Level | Meaning                                 | UI Alias           |
| -------------------- | ----- | --------------------------------------- | ------------------ |
| `EventId`            | L1    | Stable event identifier                 | none               |
| `RegistrationId`     | L1    | Stable attendee registration identifier | confirmation ref   |
| `RegistrationStatus` | L1    | Registration lifecycle state            | booking state      |
| `EventCapacity`      | L1    | Integer seat capacity rule              | seats              |
| `PublicationStatus`  | L1    | Public visibility state for one plan    | live / withdrawn   |
| `EventPublication`   | L1    | Public projection published from a plan | live catalog entry |
| `PublicationCopy`    | L1    | Market-facing text owned by publication | public copy        |
| `Track`              | L1    | Operational format label                | format             |
| `Reserve seat`       | L2    | Public CTA                              | reserve / register |
| `Create event`       | L2    | Admin CTA                               | add event          |
| `Publish event`      | L2    | Admin CTA                               | publish            |
| `Edit copy`          | L2    | Admin CTA                               | edit publication   |
