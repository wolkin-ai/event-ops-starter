# Skill Matrix

| Skill                      | Role                               | Trigger                                          |
| -------------------------- | ---------------------------------- | ------------------------------------------------ |
| `safe-change-flow`         | Safe execution guardrails          | Any code or config change                        |
| `define-domain-language`   | L1/L2 naming and glossary work     | Domain naming, contract cards                    |
| `story-ui-spec`            | Storybook-first slice spec         | New UI state or story work                       |
| `design-public-ui`         | Public experience design           | Landing pages, event detail, marketing-facing UI |
| `design-admin-ui`          | Dense operations UI                | Tables, forms, admin dashboards                  |
| `implement-domain-usecase` | Domain and use case implementation | Domain/application logic work                    |
| `review-architecture`      | Layering and dependency review     | Structure or boundary changes                    |
| `review-security`          | Security-focused review            | Forms, auth, PII, external input                 |
| `review-performance`       | Performance-focused review         | Rendering, data flow, bundles                    |
| `investigate-issue`        | Investigation workflow             | Bugs, regression analysis                        |
