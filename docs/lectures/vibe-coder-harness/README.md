# Vibe Coder Harness Course

バイブコーダー向けに、ハーネスエンジニアリングを非エンジニアでも追える順番で整理する講義メモ置き場です。

## Audience

- エンジニアリング未経験または初学者
- バイブコーディングでアプリやUIを触りたい人
- 用語の定義より先に、作業の流れと道具の役割を理解したい人

## Format

- 1ファイル = 1講義
- 連番で管理する
- 前半は体験と道具中心、後半で設計思想へ進む

## Notes

- 最初から DDD / Clean Architecture / TDD を前提にしない
- まずは Storybook、ESLint、verify、ログなどの「触って分かるもの」を先に置く
- 専門用語は役割で説明し、定義は後回しにする
